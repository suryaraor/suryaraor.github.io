Privacy Policy: claude-gmail

Last updated: November 9, 2026

claude-gmail is a personal tool built and used only by its owner, Surya Rayarao. It is not offered to the public, and no one else uses it.

What it accesses

With the owner's consent, it uses Google's OAuth to read, label, and draft email in the owner's own Gmail account, and to manage basic Gmail filter settings.

How data is handled

  • OAuth tokens are stored only on the owner's personal computer.
  • Email content is processed on that computer to help the owner organize and respond to their own mail. When an AI assistant (Anthropic's Claude) is used, the relevant message content is sent to it for processing under Anthropic's terms.
  • No data is sold, shared with advertisers, or used for any purpose other than the owner's own email management.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
